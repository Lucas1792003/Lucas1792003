## `01` &nbsp; About

I work where the interface meets the infrastructure. At **CyfroSec** I build the frontend of a cybersecurity platform, and I also work on the cloud setup it runs on. Working on both sides means I think about a feature all the way from the component tree to the container it ships in.

Security products are full of things you can't see: services talking to each other, layers of protection, and data moving between systems. Much of what I enjoy is making those ideas visible, so that someone can understand the system by looking at it rather than reading about it. That idea grew into a 3D city where each part of the platform has its own place.

Building that city got me into rendering and performance. I now care about keeping animation smooth, keeping frame rates steady and being careful with resources. Outside of work I spend time on AI and on robotics and IoT projects, mostly the ones where software ends up controlling real hardware.

## `02`  Featured — 3D City Cinematic

A cybersecurity platform has many parts, and this project shows them as one connected city. Each part of the platform becomes its own district, with animated infrastructure between them, and cinematic camera moves guide you through how they fit together. I built it to explain a complex system visually without simplifying it.
